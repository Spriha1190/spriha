## Deployment (GitHub Pages / Netlify / Vercel)

This folder (`New folder`) contains **only** static publishable website assets with zero build tools required:
1. Upload the contents of this folder directly to a repository (e.g. `spriha1190.github.io/spriha`) or drag-and-drop onto Netlify Drop / Vercel.
2. To replace the portrait with an even higher-resolution studio photo later, overwrite `assets/images/spriha-portrait.png` keeping the exact filename.
3. Separate presentation slides and CV PDF exports are stored outside this folder in `F:\spriha project 1\`.
