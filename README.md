## Tech Stack & Architecture

- **Semantic HTML5** (`<header>`, `<nav>`, `<main>`, `<article>`, `<dialog closedby="any">`, `popover="auto"`, `<audio>`, `<canvas>`)
- **Modern CSS3** (`color-scheme`, `light-dark()`, `@container` queries, pointer spotlight variables, `@media print` A4 CV formatting)
- **Modular Vanilla JavaScript** (`WebGL2` fluid caustic shader, `ResizeObserver` adaptive navbar, `Ctrl+K` command palette, ARIA-synced form validation)
- **Production Deployment Config** (`vercel.json` HTTP security headers, `robots.txt`, `sitemap.xml`)
